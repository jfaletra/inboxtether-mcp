# InboxTether MCP assets

Active full-logo, README, social-preview, and icon exports use the InboxTether MCP identity and tagline. The envelope/bridge/circuit motif and navy/blue palette are retained, with a central security shield added to the new design. Small icons omit lettering for readability.

plugin-icon-256.png is 256 × 256 and 3,363 bytes. social-preview.png is 1280 × 640 and under 1 MB. icon-64.png and icon-128.png support small-scale use. Separate full-resolution raster masters are included; no SVG/vector original is claimed.

original/approved-design-reference.png is the preserved, byte-identical historical reference. It intentionally retains the prior wordmark and is not active public-facing branding. Do not overwrite it.

See ../BRANDING.md, ../docs/ARTWORK-PROVENANCE.md, and BRANDING-RIGHTS.txt. Artwork is outside MIT and has owner-authorized project distribution. No live icon or repository upload occurred.
