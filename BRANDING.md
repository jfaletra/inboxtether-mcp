# InboxTether MCP visual identity

Name: **InboxTether MCP**. Tagline: **Your email. Your AI. Your control.** Repository target: **jfaletra/inboxtether-mcp**, initially Private only after explicit authorization.

The design retains the approved navy/blue palette, silver-white envelope, cyan arched bridge, and circuit-node motif. A central security shield was added to match the new brief; the supplied historical reference did not have a distinct shield. The shield is a branding motif, not a certification or claim of implemented draft/send functionality.
