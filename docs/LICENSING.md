# Licensing review

The root LICENSE contains the standard MIT permission, notice-preservation condition, and warranty/liability disclaimer, with a project copyright line. The operative text was compared with the [Open Source Initiative's MIT text](https://opensource.org/license/mit). An earlier explanatory scope paragraph was moved out of LICENSE to keep the license text standard.

MIT applies to this project's application source, tests, and documentation. This package does not vendor the MCP SDK, tunnel client, GitHub Actions code, or their dependencies; those independently distributed components keep their own licenses. Declaring this project MIT does not relicense third-party components or establish copyright ownership beyond the project's rights.

Artwork under assets/ is a separate category, excluded from MIT by the repository documentation and assets/BRANDING-RIGHTS.txt. On October 17, 2026 the project owner explicitly confirmed ownership/permission for public distribution of the approved logo and prepared derivatives and requested that branding remain outside MIT. That permission closes the project's owner-authorization gate for distributing these assets as project identity.

No general right to reuse or modify the branding for another project is granted. This review verifies the recorded authorization and file provenance, not independent third-party copyright/trademark clearance or registered trademark status. No copyright assignment or exclusive-rights claim is inferred from AI-assisted generation.

The original artwork is preserved byte-for-byte, and derivative provenance/prompts are in ARTWORK-PROVENANCE.md. Approval to distribute the artwork does not authorize creating a repository, uploading a live plugin icon, changing Public visibility, or creating a release.
