Connection configuration
Locate the downloaded helper first. If you saved it in Downloads, these commands work from any current directory:
macOS / Linux Terminal:
python3 "$HOME/Downloads/connect_inboxtether_claude.py"
Windows PowerShell:
py -3 "$HOME\Downloads\connect_inboxtether_claude.py"
If you saved it elsewhere, replace the quoted path with the file's actual full path. Alternatively, change Terminal to the containing folder first, then run python3 ./connect_inboxtether_claude.py (Windows: py -3 .\connect_inboxtether_claude.py). Review the displayed connection, confirm ADD-INBOXTETHER, then restart Claude Desktop. No JSON editing is needed.
